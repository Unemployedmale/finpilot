# FinPilot 2.0

## AI-Powered Financial Exception Intelligence

FinPilot is a portfolio project exploring how machine learning, deterministic financial controls, and AI-assisted investigation can reduce manual financial review workload.

The system is designed to transform fragmented transaction data into a prioritised exception workflow, helping finance teams focus human attention on transactions that are uncertain, anomalous, or financially material.

## Core Problem

Finance teams often work with transaction data spread across accounting systems, bank exports, expense platforms, and spreadsheets.

FinPilot investigates whether financial review can be improved by automatically processing high-confidence transactions while escalating potentially important exceptions for human review.
